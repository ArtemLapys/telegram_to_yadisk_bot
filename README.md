# Telegram Bot To Yandex Disk
Бот на базе Python, для загрузки файлов и работы с папками на [Яндекс Диск](https://disk.yandex.ru) из [Telegram](https://telegram.org).

## Особенности бота
- Бот использует [Telegram Bot API](https://core.telegram.org/bots/api) для взаимодействия между пользователем и Яндекс Диском.
- Пользователь из Телеграмм может:
  - загружать файлы до 20МБ,
  - создавать папки,
  - перемещаться между папками,
  - сохранять любую ссылку на диске.
- Бот переименовывает загружаемые файлы, для исключения перезаписи на Яндекс Диске. Информация о новом имени выводится после сохранения файла.
- Бот информирует пользователя о статусах каждого из файлов, так как [Telegram Bot API](https://core.telegram.org/bots/api) может выдавать ошибку по независящим от приложения причинам.

## Важная информация
- Перед сохранением файла нужно выбрать папку. ❗Сохранять файлы в корень Яндекс Диска - Запрещено. Это правило введено ради безопасности и добавления структуры на облачном диске.
- Бот переименовывает загружаемые файлы, для исключения перезаписи на Яндекс Диске. Это особенности используемой библиотеки загрузки файлов. При успешной отправки - бот подскажет новое имя.
- Бот принимает файлы размером до 20 МБ. Это сделано из-за ограничений [Telegram Bot API](https://core.telegram.org/bots/api) и использумой библиотеки [aiogram](https://github.com/aiogram/aiogram).
- Бот завершает сеанс загрузки файлов через ⌛️5 минут, после последнего сообщения пользователя. Это сделано для безопасности и исключения ошибок сохранения файлов по неправильному пути.
- Бот принимает **3 типа** данных:
  - Файлы до 20 МБ.
    -  Изображения, отправленные в виде файла. ‼️ Это сделано специально, для сохранения качества исходного изображения. ‼️ Они должны быть загружены без сжатия(при отправке боту убрать галочку _Сжать изображение(Compress the image)_).
    -  Видео, отправленные в формате файла.
    -  Любой другой файл.
  - Видео, с применением сжатия(настройка используется по умолчанию в Телеграмм).
  - Ссылка, через команду /link. Обязательно нужно указывать имя для ссылки.

## Установка и запуск бота

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ArtemLapys/telegram_to_yadisk_bot.git
   cd telegram_to_yadisk_bot
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Создайте файл `.env` в корневом каталоге и добавьте следующие данные:
   ```
   #токены для работы приложения
   TELEGRAM_API_TOKEN=<токен бота телеграмм, выданный @BotFather>
   YADISK_TOKEN=<токен от Яндекс Диска>

   #токены для авторизации пользователей Телеграмм в боте
   USER_TOKENS={"<токен>": "<имя, которое будет отображаться в названии файлов>", "<токен>": "<имя, которое будет отображаться в названии файлов>"} 
   ```
   - [Как получить токен для бота Телеграмм?](https://core.telegram.org/bots/features#creating-a-new-bot)
   - [Как получить токен от Яндекс Диска?](https://github.com/MVKozlov/GMYandexDisk?tab=readme-ov-file#%D0%BF%D0%BE%D0%BB%D1%83%D1%87%D0%B5%D0%BD%D0%B8%D0%B5-oauth-%D1%82%D0%BE%D0%BA%D0%B5%D0%BD%D0%BE%D0%B2)

5. Запустите бота:
   ```bash
    python3. main.py
   ```

## Сценарии работы с ботом в Телеграмм
### Сохранение файла на Яндекс Диск
1. Пользователь заходит в бот Телеграмм и запускает его(`/start`).
2. Вводит токен авторизации(`/login <токен>`, который предоставляет администратор бота. Токен прописывается в `.env` файле.
3. Вводит команду `/upload`, активирующую загрузку файла и демонстрирующую папки Яндекс Диска.
4. Выбирает папку `/folder <номер папки>` или создает новую `/newfolder <название папки>`, в которую хочет сохранить файл. ❗Сохранять файлы в корень Яндекс Диска - Запрещено. 
5. Отправляет файл в папке или выбирает подпапку, создает новую.
6. При успешной отправки файла, бот подскажет его новое имя и путь на Яндекс Диске. В имени файла обязательно указывается имя пользователя, который загрузил файл. Имя задает администратор бота.

### Сохранение ссылки на Яндекс Диск
1. Пользователь заходит в бот Телеграмм и запускает его(`/start`).
2. Вводит токен авторизации(`/login <токен>`, который предоставляет администратор бота. Токен прописывается в `.env` файле.
3. Вводит команду `/upload`, активирующую загрузку ссылки и демонстрирующую папки Яндекс Диска.
4. Выбирает папку `/folder <номер папки>` или создает новую `/newfolder <название папки>`, в которую хочет сохранить ссылку. ❗Сохранять ссылки в корень Яндекс Диска - Запрещено. 
5. Отправляет ссылку командой `/link <ссылка> <имя ссылки>`.
6. При успешном сохранении ссылки, бот подскажет её путь на Яндекс Диске.

## Структура проекта
```bash
telegram_to_yadisk_bot/
├── commands/              # Обработчики команд Telegram
│   ├── file_handler.py    # Обработка файла перед загрузкой на Яндекс Диск
│   ├── folder.py          # Переход и выбор между папками
│   ├── help.py            # Обработчик команды /help(текстовое сообщение)
│   ├── link.py            # Обработчик команды /link(сохранение ссылки в файл на Яндекс Диске)
│   ├── newfolder.py       # Обработчик команды /newfolder(создание новой папки на Яндекс Диске)
│   └── upload.py          # Обработчик команды /upload(активация загрузки файла)
├── services/              # Описание логики работы с сервисами
│   └── yadisk_services.py # Логика работы с Яндекс Диском
├── auth.py                # Обработка команды /login(проверка аутентификации пользователя Телеграмм)
├── config.py              # Конфигурация проекта, загрузка данных из .env
├── main.py                # Точка входа (инициализация бота), регистрация обработчиков команд
├── requirements.txt       # Зависимости приложения
├── states.py              # Хранение временные данные приложения
└── .env                   # Токены Яндекс Диска, Телеграмм и авторизации пользователей
```
